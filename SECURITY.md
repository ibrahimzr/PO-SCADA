# Security and Publication Scope

This repository is a sanitized portfolio representation of the PO-SCADA project.

The following are intentionally **not** published:

- Ignition Gateway backup files (`.gwbk`)
- Passwords or user credentials
- Node-RED credential stores
- API keys, tokens, secrets, or private connection material
- Production/site configuration data

The project is a software/simulation commissioning environment. It is not a production Safety Instrumented System, SIL validation, or site SAT record.
